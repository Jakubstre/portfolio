A SMALL GRAPHIC DESIGN PROJECT CREATED FOR A PUBLIC LARP GAME PLAYED ACROSS SEVERAL SCHOOLS IN SLOVAKIA, TURNING EACH CHARACTER INTO A TANGIBLE IDENTITY THROUGH A SIMPLE AND FUNCTIONAL ID CARD SYSTEM.

* HIGHLIGHTS

→ SCOPE & IMPACT

  • Developed a consistent ID card system for individual LARP characters.
  • Combined character names, roles, typography, and graphic elements into a unified visual identity.
  • Created multiple colour variations to distinguish characters while maintaining visual consistency.
  • Designed the cards with both digital presentation and physical print use in mind.
  • Produced final mockups showing how the identity translates from screen to a tangible object.
